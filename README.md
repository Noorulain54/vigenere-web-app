# vigenere-web-app
# 🔐 Vigenère Cipher Web App

A simple, mobile-friendly web application that lets you **encrypt** and **decrypt** messages using the **Vigenère Cipher**. Built with **Python (Flask)** and basic **HTML/CSS**.

---

## 🔧 Features

✅ Clean UI (works on mobile)  
✅ Encrypt or Decrypt any message using a keyword  
✅ Auto removes punctuation and symbols  
✅ Simple and beginner-friendly codebase  
✅ Open-source and customizable  


## 🚀 How It Works

- The app uses the **Vigenère Cipher**, a form of polyalphabetic substitution.
- You provide a **message** and a **key** (word), and the app will:
  - Encrypt it if you choose "Encrypt"
  - Decrypt it if you choose "Decrypt"
